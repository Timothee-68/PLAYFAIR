Playfair Display — специмен шрифта

Одностраничный сайт о шрифте Playfair Display в стилистике виниловых пластинок. Учебный проект, 2026.

Сайт: https://timothee-68.github.io/PLAYFAIR/

О проекте

Сайт рассказывает о шрифте Playfair Display: его начертаниях, знаках, поддержке языков и истории создания. Визуальная идея — шрифт как пластинка: начертания показаны на «яблоках» винила, а разделы оформлены как конверты, билет и заметки звукорежиссёра.

Как сделано
Дизайн — мой: макет нарисован в векторе (Figma), ширина 1440px.
Вёрстка — HTML и CSS, без JavaScript и библиотек.
Шрифты — Playfair Display и Inter (Google Fonts).
Волнистые фоны экспортированы из макета в SVG (папка img).
